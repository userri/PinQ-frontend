# 스토어 에셋

Play Console 에 올리는 이미지. **APK 와 별개**라 앱을 배포해도 자동으로 안 바뀐다 —
아이콘·피처 그래픽·스크린샷은 콘솔에서 따로 교체해야 반영된다.

| 파일 | 규격 | 자리 |
|---|---|---|
| `app_icon_512.png` | 512×512 | 앱 아이콘 |
| `feature_graphic_1024x500.png` | 1024×500 | 피처 그래픽 |
| `screenshots/01~07` | 1080×1920 | 폰 스크린샷(최대 8장) |

## 규격에서 꼭 지킬 것

**피처 그래픽은 좌우 각 15%(154px)를 비운다.** 데스크톱 목록 카드가 약 1.8:1 로 렌더돼
좌우가 중앙 크롭된다(한쪽 약 60px). 이걸 몰라서 로고와 헤드라인 첫 글자가 잘렸던 적이 있다.
상하도 각 40px 여유. 헤드라인 최소 48px — 목록에서 1/3 로 축소돼 뜬다.

**앱 아이콘은 마스크 없이 정사각으로.** 미리 둥글게 만들면 스토어 라운딩과 이중으로 깎여 잘린다.

**피처 그래픽에 앱 아이콘·앱 이름을 넣지 않는다.** 스토어가 바로 아래에 붙여준다.

## 스크린샷 순서

앞 3장만 스크롤 없이 보인다 → **행동 → 지식 → 습관**.

1. 오늘의 문제 — `오늘 아침 뉴스로 만든 문제`
2. 해설·기사 — `왜 그런지, 출처 기사까지`
3. 잔디밭 — `푼 날이 색으로 쌓여요`
4. 홈 — `하루 3분이면 끝나요`
5. 정원 — `틀린 문제는 나무가 돼요`
6. 복습 성장 — `세 번 물 주면 나무 완성`
7. 오답노트 — `놓친 문제, 언제든 다시`

캡션은 **한 장에 한 줄**. 두 줄 이상이면 광고처럼 보인다.

## 만드는 법

실기기(또는 `ShowcaseActivity`) 캡처에 캡션 밴드를 얹어 합성한다.

- 캔버스 1080×1920, 상단 캡션 밴드 340px. 제목 라임 66px(Bold) + 부제 `TextSecondary` 46px.
- 한글 폰트: `/System/Library/Fonts/AppleSDGothicNeo.ttc` — **index 6 = Bold, 2 = Medium**.
- `ShowcaseActivity` 캡처는 인셋을 적용하지 않으므로 상단 약 180px 를 잘라내야 상태바와 겹치지 않는다.
- 테스트 광고(AdMob)가 찍히지 않는 스크롤 위치를 고를 것.
- 아이콘 512 는 Showcase `store_icon` 케이스를 캡처해 중앙 정사각을 잘라 쓴다.

## 검증

**폭 300px 와 150px 로 줄여 나란히 본다.** 스토어에서 실제로 보이는 크기가 그 정도다.
그 크기에서 무슨 앱인지 안 읽히면 답이 아니다 — 논쟁보다 빠르다.
